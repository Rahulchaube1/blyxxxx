# Blyx TextMate grammar

Syntax highlighting for `.blyx` files. The grammar declares the TextMate scope `source.blyx` and is distributed under the MIT license.

The standalone repository is [Rahulchaube1/language-blyx-grammar](https://github.com/Rahulchaube1/language-blyx-grammar). The grammar is developed and tested in the [Blyx language repository](https://github.com/Rahulchaube1/blyxxxx/tree/blyx-main/linguist-grammar). Submit grammar changes there and update both the editor and export copies. The export test compares the grammar, language registration and license.

Editors that load TextMate grammars can register `grammars/blyx.tmLanguage.json` under `source.blyx` for the `.blyx` extension. VS Code users can install the [Blyx Language extension](https://marketplace.visualstudio.com/items?itemName=RahulChaube.blyx-language).
