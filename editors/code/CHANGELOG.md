# Change Log

All notable changes to the **Blyx Language** extension are documented here.

## 1.2.4

- Show the Blyx logo beside `.blyx` files in light and dark themes that support language icons.

## 1.2.3

- Expand the extension guide with a runnable example, expected output, troubleshooting, and links to the project and maintainer.

## 1.2.2

- Size the website artwork for the Visual Studio Marketplace icon limit.

## 1.2.1

- Use the Blyx website logo as the extension icon.

## 1.2.0

- Run the current buffer with the bundled Blyx interpreter.
- Receive parser diagnostics while editing, including unsaved files.
- Execute floating-point and vector math locally.

## [0.1.0-alpha]

### Added
- Blyx syntax highlighting for `.blyx` source files.
- Starter snippets for common Blyx declarations and language constructs.
- Repository and marketplace metadata aligned with the open-source Blyx project.

### Status

The extension currently provides language syntax and snippets. Full LSP diagnostics, navigation, formatting, debugging, and other editor features depend on the maturity of the corresponding Blyx tooling and are not advertised here as complete.
