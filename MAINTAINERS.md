## Working Groups

1. **Compiler Working Group (`compiler/`)**:
   - Oversees lexer, AST, parser, type checker, and intermediate representations.
   - Lead: Rahul Chaube (@Rahulchaube1)

2. **Standard Library & Runtime Working Group (`library/`)**:
   - Maintains memory allocators, actor runtime, tensor operators, and concurrency primitives.

3. **Toolchain & Developer Experience Working Group (`tools/`)**:
   - Maintains `blyxpkg`, `blyxfmt`, `blyx-analyzer` (LSP), `blyxdoc`, `blyxdbg`, and `blyxup`.

4. **Security & Release Management**:
   - Coordinates vulnerability disclosures, cryptographic signing, and binary release distributions.
