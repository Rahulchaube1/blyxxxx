# Blyx Community

Blyx is an open-source experiment in AI-native systems programming. The community is where language design, compiler engineering, runtime work, benchmarks, and real-world feedback meet.

## Start here

1. Try the playground: https://play.blyx-lang.space
2. Read the documentation: https://www.blyx-lang.space/learn
3. Browse open issues: https://github.com/Rahulchaube1/blyxxxx/issues
4. Join design discussions: https://github.com/Rahulchaube1/blyxxxx/discussions

## What we want from contributors

We value concrete technical contributions over hype:

- reproducible compiler bugs
- language and type-system proposals
- compiler optimizations
- runtime and concurrency work
- tensor and accelerator experiments
- tooling and LSP improvements
- documentation and examples
- benchmark methodology and independent measurements

## RFCs and language design

Large language or compiler changes should be discussed before implementation. A good proposal explains the problem, motivation, semantics, alternatives, compatibility implications, and how the change can be tested.

## Benchmarking

Please include enough information to reproduce performance claims: source, Blyx version/commit, target hardware, compiler configuration, competing implementation, and measurement method.

## Code of conduct

Please keep discussions technical, constructive, and respectful. Read `CODE_OF_CONDUCT.md` before participating.

## Important project status

Blyx is currently alpha software. Syntax, APIs, compiler behavior, and tooling can change. Community members should distinguish implemented behavior from proposed or experimental design.

## Share the project responsibly

If you write about Blyx, link to the canonical repository and official website, describe the current alpha status, and avoid presenting experimental results as established production benchmarks.
